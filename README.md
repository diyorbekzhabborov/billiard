# Billiard Club CRM Pro (Бильярд & Game Club CRM)

Специализированная CRM-система для бильярдных клубов и игровых зон (Русский бильярд, Пул, Снукер, VIP залы, PlayStation 5) с мультиарендной архитектурой и закрытой панелью управления.

---

## 🔒 Вход для покупателей клубов (Клиентский вход)

Клиенты заходят по адресу:
👉 **`http://localhost:5173`**

- Отображается только стильный экран ввода 4-значного PIN-кода.
- Никаких списков других клубов, чужих данных или кнопок регистрации покупатели не видят.
- По умолчанию настроена учетная запись с кодом: **`1111`**.

---

## 🛡 Скрытая панель Супер-Администратора (Для вас)

Для подключения новых клубов и управления учетными записями перейдите по адресу:
👉 **`http://localhost:5173/admin`**

### Данные для входа в админку:
- **Логин**: `admin1`
- **Пароль**: `admin`

### В админ-панели вы можете:
1. Видеть список всех проданных клубов, их PIN-коды и количество столов.
2. Подключить новый клуб: нажать кнопку **«Добавить новый клуб»**, указать название (например, *«Бильярдный Клуб "Олимп"»*), задать для него уникальный 4-значный PIN-код (например, `2222`) и валюту.
3. Изменить PIN-код любого клуба или удалить неактивный клуб.

---

## 💻 Быстрый запуск на Windows

Просто запустите файл **`start.bat`** в папке `d:\Новая папка\billiard-crm`.
